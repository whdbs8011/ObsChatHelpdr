# 치지직 OBS 채팅창

OBS에서 치지직 채팅을 보고 방송 제목과 카테고리를 바꿀 수 있습니다.

## 처음 한 번만 설정하세요

1. 받은 ZIP 파일을 **압축 풀기** 하세요.
2. OBS를 열고 **도구 → 스크립트**를 누르세요.
3. **＋ 버튼**을 누르고, 압축을 푼 폴더 안의 **Stream-Dock-OBS.lua**를 선택하세요.
4. OBS에서 **독 → 사용자 지정 브라우저 독**을 여세요.
5. 이름에는 **치지직 관리**, 주소에는 아래 내용을 넣고 **적용**을 누르세요.

   ```text
   http://localhost:18765/
   ```

6. 새로 열린 창에서 **치지직 로그인**을 누르세요.

이제부터는 **OBS만 켜면 됩니다.** 다른 프로그램을 매번 실행할 필요가 없습니다.

## 사용 방법

- **채팅 보내기:** 아래 입력창에 적고 Enter 또는 동그란 ↑ 버튼을 누르세요.
- **줄바꿈:** Shift와 Enter를 함께 누르세요.
- **채팅 관리:** 채팅에 표시된 닉네임을 누르세요.
- **방송 정보 변경:** 방송 설정 탭에서 제목·카테고리·태그를 바꾸세요.

## 기억해주세요

- 압축을 푼 폴더는 **옮기거나 삭제하지 마세요.** OBS 플러그인 폴더에 넣을 필요도 없습니다.
- 로그인 화면이 다시 나오면 치지직에 다시 로그인하세요.
- 화면이 이상하면 독을 우클릭해 **새로고침**하세요.
- `Stream-Dock.cmd`는 필요할 때 수동으로 여는 보조 파일입니다. 평소에는 누르지 않아도 됩니다.
- 친구에게는 **처음 받은 ZIP 파일**을 보내세요. 사용 중인 폴더에는 내 로그인 정보가 저장됩니다.
